# DiBSE Jahrgang 2026 🎓

Willkommen! Dieses Repo gehört euch: Hier verewigt sich der gesamte Jahrgang mit einem kurzen Steckbrief.

## Mitmachen (das Rezept aus der Welcome-Session)

1. 🌐 Oben rechts auf **„Fork"** klicken → „Create fork"
2. 🌐 In **EUREM** Fork: grüner **„Code"**-Button → URL kopieren
3. ⌨️ `git clone <URL-eures-Forks>` → `cd DiBSE_eCollaboration_Git`
4. ⌨️ `git switch -c steckbrief_vorname_nachname`
5. ⌨️ `notepad jahrgang_2026/vorname_nachname.md` → „Datei anlegen?" → Ja → Vorlage ausfüllen (siehe unten) → speichern & schließen
6. ⌨️ `git add .` → `git commit -m "Steckbrief Vorname Nachname"` → `git push -u origin steckbrief_vorname_nachname`
7. 🌐 GitHub zeigt euch einen gelben Banner: **„Compare & pull request"** → klicken → „Create pull request"

> ⚠️ Beim ersten `push` öffnet sich ein Browser-Fenster zum GitHub-Login – das ist normal! Einmal einloggen, gilt für immer.

**Wichtig:** Überall wo *vorname_nachname* steht, kommt **euer** Name hin (klein, ohne Umlaute). Legt **nur eure eigene Datei** an und ändert keine fremden Dateien – dann gibt es garantiert keine Merge-Konflikte.

## Vorlage für deinen Steckbrief

Eure Datei heißt `jahrgang_2026/vorname_nachname.md` – eine fertige Vorlage liegt hier: [vorname_nachname.md](jahrgang_2026/vorname_nachname.md)

```markdown
# Vorname Nachname

- Kommt aus: …
- Warum DiBSE: …
- Fun Fact: …
```

## Regeln

- Ein PR pro Person, eine Datei pro Person
- Nur Inhalte, die ihr auch am Beamer vor dem ganzen Jahrgang sehen wollt 😉
